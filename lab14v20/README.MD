
# Лабораторна робота №14

## Тема
HashSet/Queue/Stack: практичні сценарії.

## Варіант 20
Система рекомендацій.

## Мета
Навчитися використовувати колекції HashSet<T>, Queue<T> та Stack<T> для розв'язання практичних задач.

## Реалізація

- HashSet<string> — зберігання унікальних продуктів для рекомендацій. Повторні продукти не додаються.
- Queue<string> — черга користувачів для обробки за принципом FIFO.
- Stack<string> — історія переглянутих рекомендацій за принципом LIFO.

## Результат
Програма демонструє додавання, видалення та пошук продуктів, додавання й обробку користувачів, перегляд і видалення історії рекомендацій.
