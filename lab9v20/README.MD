# Лабораторна робота №9

**Тема:** Поліморфні сервіси: Notification (Email/SMS/Push).

**Варіант 20. Пошук даних — SearchEngine**

* Базовий клас: `abstract class SearchEngine`.
* Похідні класи: `LocalSearch`, `DatabaseSearch`, `WebSearch`.
* Метод: `abstract List<string> Search(string query)`.
* Валідація: перевірка, що `query` не є порожнім.

# Хід роботи:

У ході виконання лабораторної роботи №9 я створив консольний проєкт на C# у Visual Studio Code за допомогою команди `dotnet new console`. Реалізував абстрактний клас `SearchEngine` та три похідні класи: `LocalSearch`, `DatabaseSearch` і `WebSearch`.

Кожен клас має власну реалізацію методу `Search()` та перевірку пошукового запиту. Для роботи з усіма реалізаціями було створено клас `SearchService` з методом `SearchAll()`, який працює зі списком базового типу `SearchEngine`.

У `Main()` було створено список пошукових систем, виконано пошук за різними запитами та продемонстровано обробку помилки при порожньому запиті.
