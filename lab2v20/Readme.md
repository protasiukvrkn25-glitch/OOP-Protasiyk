# Лабораторна робота №2: Клас із кількома конструкторами. Життєвий цикл об’єкта.

**Дисципліна:** Об’єктно-орієнтоване програмування  
**Навчальний заклад:** Рівненський фаховий коледж інформаційних технологій  
**Варіант:** 20 (Клас Figure)  

---

## Мета роботи
Навчитися реалізовувати перевантажені конструктори, дослідити порядок їх викликів та зрозуміти основи життєвого циклу об’єкта в C#.

---

## Використані технології та інструменти
* **Мова програмування:** C#
* **Платформа:** .NET SDK
* **IDE:** Visual Studio / VS Code / Rider

---

## Завдання за варіантом №20

Реалізувати клас **Figure**, який містить:
1. **Приватні поля:**
   * `_name` (`string`)
   * `_color` (`string`)
   * `_area` (`double`)
2. **Публічні властивості:**
   * `Name`, `Color`, `Area` (з валідацією: площа не може бути від’ємною).
3. **Конструктори:**
   * Параметризований конструктор (`name`, `color`, `area`).
   * Конструктор за замовчуванням (`Name="Circle"`, `Color="Red"`, `Area=0.0`), який викликає параметризований за допомогою ключового слова `: this()`.
4. **Метод:**
   * `GetFigureInfo()` — повертає рядок з інформацією про фігуру.
5. **Деструктор (Фіналізатор):**
   * `~Figure()` — виводить повідомлення про знищення об’єкта з пам'яті.

---

## Виконання програми (Program.cs)

У методі `Main` продемонстровано:
* Створення об'єктів за допомогою різних конструкторів.
* Виклик методів об'єктів.
* Примусовий виклик збирача сміття (`GC.Collect()` та `GC.WaitForPendingFinalizers()`) для відстеження роботи деструкторів.
